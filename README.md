# Vloog.ai

AI-powered tool that converts video vlogs into SEO-ready blog
posts and Canva poster prompts — built solo, self-taught.

## What it does
Drop in a video (upload or any URL) and get back a publish-ready
blog post plus a matching Canva poster brief — with your choice
of length, tone, and language.

## How it works
1. **Transcribe** — Whisper turns the video's audio into text
2. **Draft** — an AI model writes the first blog pass
3. **Verify** — a second pass rereads the transcript and strips
   out anything the draft invented that wasn't actually said
4. **Poster brief** — a ready-to-use Canva design brief is
   generated from the finished post

## Built with
Python, Streamlit, Groq-hosted models (Whisper + an LLM for drafting)
